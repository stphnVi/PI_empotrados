### Proyecto de Casa Inteligente con Sistema Empotrado e IoT 

## Curso de Sistemas Empotrados

## Resumen

Este proyecto implementa una casa inteligente utilizando tecnologías de sistemas empotrados como Raspberry Pi, programación en Python, desarrollo de apps móviles en Java, y la construcción de distribuciones Linux personalizadas con Yocto. Integra cámaras y actuadores controlados mediante protocolos de red como sockets LAN, con enfoque en eficiencia, sostenibilidad y seguridad. El objetivo fue desarrollar una solución adaptable, escalable y orientada al usuario, aplicando buenas prácticas de ingeniería.

---

## Requerimientos

- Raspberry Pi 4
- Leds
- Cable UTP
- Imagen de YOCTO base
- Android studio, SDK 15.0 VanillaIceCream
- python3
